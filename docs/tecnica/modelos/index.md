# Modelos de proyección

Qué modelo produjo cada revisión publicada, tal como lo dice su informe. En la etapa 1 la plataforma no corre modelos (P-0001): esta sección solo documenta los modelos de las revisiones que se cargan, para entender sus cifras y su error. En la base, el modelo de cada revisión es un texto corto en `core.revisions.model`; el detalle vive aquí.

**Toda afirmación cita el informe y la página donde se dice (PFU-03).** Se cita la página impresa en el informe y, si el PDF numera distinto, también la del PDF. Lo que el informe no dice no se escribe como hecho: se anota como duda para el equipo de modelación (X-23) o como dato por confirmar (X-32).
